## 5. Normalização

### 5.1 Fim de linha (NORMALIZE-01)

Sem `.gitattributes` e com `core.autocrlf=true`, 718 arquivos de texto ficavam com LF no índice e
CRLF no worktree e um (`{.gitignore`, sic `.gitignore`) com EOL misto. Corrigido com
`* text=auto eol=lf` + binários declarados + `scripts/check-eol.sh`.

```
ANTES:  FAIL: .gitattributes ausente …; FAIL: 1 arquivo(s) com fim de linha misto   -> rc=1
DEPOIS: OK: normalizacao de fim de linha em dia (1305 arquivos conferidos)          -> rc=0
```

### 5.2 Unicode na busca (NORMALIZE-02)

O banco guarda NFC (`Poção` = `c3 a7 c3 a3`) e a rota comparava string crua:

```
antes   ?q=po%C3%A7%C3%A3o (NFC) -> 20    ?q=po%63%CC%A7a%CC%83o (NFD) -> 0
depois  ?q=po%C3%A7%C3%A3o (NFC) -> 20    ?q=po%63%CC%A7a%CC%83o (NFD) -> 20
```

Teste de unidade (`portal/src/lib/itemsearch.test.ts`), rodado com e sem a chamada
`.normalize("NFC")`:

```

```
