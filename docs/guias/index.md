## Regra de escrita

Guia que descreve comportamento precisa dizer **como se verifica**. "O EXP aparece no painel" é
afirmação; "mate um mob e o valor aparece no painel de EXP, sem linha no chat (`mobkilled.go`,
`MsgExpPanel`)" é guia. O que ainda não foi medido entra marcado como **UNVERIFIED**, com o que falta
para confirmar.
