# Comandos e utilidades do jogador

A lista canônica de comandos in-game, com o que cada um faz no servidor atual, está em
[Comandos in-game](../../game.md). Esta página cobre só o que muda a vida de quem joga no dia a dia.

## Troca de canal

```
/srv <canal>
```

Troca de servidor sem redigitar senha (token de 2 minutos). Ver
[Primeiros passos](comecando.md#3-trocar-de-canal-sem-sair-do-jogo).

## Mensagens

O chat do jogo tem os canais normais (geral, grupo, guilda, sussurro). O servidor diferencia o canal
pelo cabeçalho do pacote; mensagem de sistema (aviso, recompensa, erro) chega em cor própria e **não**
aparece como fala do seu personagem.

## Recompensa diária

A recompensa diária é reivindicada pelo próprio jogo e o estado fica no servidor, por personagem. Se
o botão não responder, o problema é de conexão com o servidor — a recompensa **não** é dada duas
vezes: a segunda tentativa no mesmo dia é recusada.

## O que não existe

Estas ações não são comandos de jogador neste servidor (exigem papel administrativo, no portal):

- criar item, dar EXP ou mudar nível de outro personagem;
- desbloquear conta ou trocar senha de terceiro;
- abrir evento global ou alterar rate.
